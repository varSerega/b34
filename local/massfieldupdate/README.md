# Массовое изменение полей

## Установка

1. Установить зависимости из корня проекта:

```bash
composer install --no-dev --optimize-autoloader
```

2. В административной части Bitrix установить модуль `bozenko.massfieldupdate`.
3. Открыть страницу настройки прав:

```text
/local/massfieldupdate/settings.php
```

4. Выдать группам право изменения нужных полей.
5. Открыть рабочую страницу:

```text
/local/massfieldupdate/
```

## Поддержка

- CRM: лиды, сделки, контакты, компании.
- CRM-поля: стандартные и пользовательские.
- Товары: стандартные поля элементов и свойства выбранного инфоблока.
- ID: текстовый ввод, CSV/TXT и XLSX (первый столбец).

Администратор имеет доступ к изменению всех разрешённых полей. Для остальных пользователей список полей фильтруется по группам из настроек модуля, а серверная проверка выполняется повторно перед каждой операцией.
